Configuración inicial

Se hace una sola vez. Define la contraseña de administrador y conecta la app con GitHub para que pueda publicar los cambios. El token queda guardado cifrado con tu contraseña; sin ella no sirve.

Créalo en GitHub → Settings → Fine-grained tokens: Repository access = solo este repositorio · Permissions → Contents = Read and write.
Mínimo 12 caracteres. Usa una frase larga: es lo único que protege el acceso.
